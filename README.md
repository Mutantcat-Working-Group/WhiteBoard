### 一、项目简介

本项目是一个基于 **Vue 2** + **AntV G6** 构建的在线白板（WhiteBoard）应用，提供自由画布式的可视化编辑能力。用户可以在画布上自由绘制、书写、连接节点、嵌入素材，构建思维导图、流程图、笔记草图等多种可视化内容，并支持多画板切换、本地持久化与多语言（中/英）。

主要能力包括：

- **自由画布**：基于 G6 图形引擎，支持画布缩放、平移与节点拖拽。
- **基础绘图**：矩形、圆形、直线、虚线、曲线等多种图形元素的绘制与编辑。
- **文字便签**：支持富文本编辑的便签（基于 Quill）。
- **签名板**：手写签名功能（基于 signature_pad）。
- **素材库**：左侧素材栏，提供丰富的可复用图形与图标素材，支持拖拽到画布。
- **导航器**：右侧导航面板，便于在大画布中快速定位。
- **多画板**：支持创建与切换多个独立画板，状态本地保存。
- **导入导出**：支持画布内容导出与图片导出。
- **国际化**：内置简体中文 / English 两套语言。
- **PWA**：支持作为渐进式 Web 应用安装到本地。

### 二、项目特点

1. **Vue 全家桶**：基于 Vue 2 + Vue Router + Vuex + Vue CLI 构建，结构清晰、易于二次开发。
2. **G6 图形引擎**：使用 AntV G6 4.x 作为底层画布，节点/边/控制点自定义能力强。
3. **组件化设计**：画板、工具栏、素材栏、导航器、上下文菜单、便签、签名板等均以独立 Vue 组件实现，职责单一。
4. **丰富的素材**：内置 `src/assets/images` 与 iconfont 图标体系，开箱即用。
5. **可扩展的图元系统**：`src/global/lib/g6/node`、`edge` 目录提供统一的图元注册与扩展接口。
6. **本地持久化**：基于 Vuex + `localStorage` 的数据持久化方案，刷新不丢内容。
7. **多语言支持**：基于 Vue I18n，可一键切换中英文。
8. **PWA 友好**：`registerServiceWorker.js` + `manifest.json` 支持离线缓存与桌面安装。
9. **响应式画布**：支持鼠标滚轮缩放、空白处拖拽平移等交互。
